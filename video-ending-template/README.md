# Шаблон концовки abduragimov_cvs

Добавляет к любому вертикальному видео ту же концовку, что в видео-образце:

1. ник `abduragimov_cvs` из левого верхнего угла плавно едет в центр и растёт;
2. картинка размывается;
3. появляется большой ник с линией кардиограммы, которая прорисовывается слева направо со звуком;
4. кадр затемняется и застывает (~5 с).

Все тайминги, размеры, размытие и затемнение замерены покадрово с образца.

## Состав

| Файл | Что это |
|---|---|
| `add_ending.py` | скрипт, который делает всё сам |
| `assets/text_matte.png` | вырезанная из образца надпись (точные буквы) |
| `assets/ending_audio.wav` | звук концовки (тишина + звук кардиограммы) |
| `assets/params.json` | все замеренные параметры анимации |

## Как использовать в новом чате с Claude

1. Загрузите в чат новое видео и архив `video-ending-template.zip` (или откройте чат в этом репозитории, тогда архив не нужен).
2. Вставьте этот текст:

```text
Вот новое видео и мой шаблон концовки (video-ending-template.zip).
Распакуй шаблон и запусти:
python3 add_ending.py <моё видео> <результат.mp4>
(нужны ffmpeg, numpy, opencv-python-headless, pillow — установи, если нет).
Ничего в шаблоне не меняй, просто примени его к видео и пришли мне результат.
Потом посмотри несколько кадров концовки и проверь, что всё выглядит чисто.
```

## Настройки

```bash
python3 add_ending.py вход.mp4 выход.mp4                 # обычный случай
python3 add_ending.py вход.mp4 выход.mp4 --cut 12.4      # обрезать видео на 12,4 с, дальше концовка
python3 add_ending.py вход.mp4 выход.mp4 --watermark add # если ника в углу на видео нет
```

- `--cut` пригодится, если в конце видео лишние секунды: концовка начнётся с этого момента.
- `--watermark`: `auto` (по умолчанию) сам находит маленький ник в углу. `baked` — ник вшит в видео, скрипт затрёт его, когда тот начнёт двигаться. `add` — ника нет, скрипт нарисует его на всём видео. `none` — без движущегося ника.

## Как устроено

- Концовка добавляется **после** последнего кадра (+5,03 с), речь не обрезается.
  Движение ника начинается за 1,4 с до конца исходного видео, как в образце.
- Под размытием — последний кадр видео.
- Рассчитано на кадр 9:16 (720×1280, 1080×1920 и т. п.), любой fps.
- Ник в углу должен стоять там же, где в образце (так снимаются все ролики с этим ником).
