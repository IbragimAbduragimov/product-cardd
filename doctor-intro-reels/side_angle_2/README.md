# Боковой ракурс (новая съёмка) — подготовка исходника

Это **часть будущего ролика**, монтаж пока не делался. Здесь только техническая
подготовка бокового ракурса, чтобы потом монтировать его вместе с остальными частями.

## Исходник

- `IMG_7785.mov` — iPhone, HEVC 4K (2160×3840 после поворота), SDR BT.709,
  переменная частота кадров (~35 fps в среднем), 60,2 с, звук AAC 48 kHz стерео.
- Хранится в релизе репозитория (в git не кладём — 233 МБ):
  https://github.com/IbragimAbduragimov/product-cardd/releases/download/Sourse/IMG_7785.mov
  SHA-256 `625ffee9e799ee712b62cd5bc691234dc8579ad791ce6282e9c9a9ceca337e68`
- Локально ожидается в `doctor-intro-reels/sources/IMG_7785.mov`.

Кадр: врач сидит за белым столом, синий фон; слева в кадр попадают белый шкаф
с рельефной стеной и серая декоративная планка с выступами. Камера держалась
с рук: дрейф до ~150 px (4K), поворот до ±0,5°, масштаб ±2 %.

## Что сделано (`scripts/`)

1. `track.py` — трекинг камеры по неподвижному фону (стена/планка), преобразование
   подобия «кадр → опорный кадр t=15 с» для каждого кадра 30 fps. Результат —
   `build/transforms.npy` (1802 кадра; в git, чтобы не пересчитывать).
2. `process.py`:
   - **стабилизация** «как со штатива» по этим преобразованиям;
   - **приближение 1,5×**: окно 1440×2560 из 4K (x 470–1910, y 760–3320 в координатах
     опорного кадра) — только исходные пиксели, без увеличения; для Reels 1080×1920
     это даунскейл, т. е. качество не теряется;
   - **стена и планка слева заменены синим фоном**: неподвижная (после стабилизации)
     маска стены до заднего края столешницы (y=1624), правая граница x = 347 + 0,03·y;
     человек поверх — маска Robust Video Matting (ResNet50) + guided filter,
     цвет края очищен от примеси стены (fgr RVM), поэтому нет светлого ореола;
     синий берётся из настоящего фона этого же кадра (цвет по строкам + зеркальная
     копия реальной фактуры/шума), поэтому совпадают шум, экспозиция и баланс.
   - Цвет не трогали — цветокоррекция будет на монтаже, единая для всех ракурсов.

## Результаты (`output/`)

- `side_angle_2_master_1440x2560.mp4` — рабочий мастер для монтажа (H.264 CRF 13,
  30 fps CFR, оригинальный звук без изменений). Большой — в git не кладётся,
  пересобирается командами ниже.
- `side_angle_2_1080x1920.mp4` — та же картинка в разрешении Reels.

## Пересборка

```bash
pip install opencv-python-headless onnxruntime numpy
# модель: https://github.com/PeterL1n/RobustVideoMatting/releases/download/v1.0.0/rvm_resnet50_fp32.onnx
export RVM_MODEL=/путь/к/rvm_resnet50_fp32.onnx
python3 scripts/track.py ../sources/IMG_7785.mov build/transforms.npy   # можно пропустить — файл есть
python3 scripts/process.py                                               # → build/video_master_noaudio.mp4
# затем звук и версия 1080×1920 — см. команды в scripts/finish.sh
```

## Для дальнейшего монтажа

- Таймлайн этого файла = таймлайн исходника (0–60,2 с), звук синхронен.
- Когда придут остальные части (фронтальная камера и т. д.) — синхронизировать
  по звуку кросс-корреляцией, как в первом ролике (`../scripts/`), основа — фронт.
