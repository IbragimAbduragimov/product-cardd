# Фронтальная камера (новая съёмка) — HDR→SDR + картина сердца

Часть будущего ролика, **монтажа пока нет**.

## Исходник

- `IMG_3483.mov` — iPhone, HEVC 4K (2160×3840 после поворота), **HDR HLG / BT.2020, 10 бит**,
  60 fps, 126,8 с, звук AAC.
- Релиз «Tags»: https://github.com/IbragimAbduragimov/product-cardd/releases/download/Tags/IMG_3483.mov
  SHA-256 `be322d55ea4e5f7ba0099d5264f02dcb3f785ef9bd226e8818e153506f8ffba6`
- Локально: `doctor-intro-reels/sources/IMG_3483.mov`.
- Камера на штативе (дрейф < 0,6 px в 1080p, ~1,7 px только в первую секунду).

## Что сделано (`scripts/poster.py`)

- HLG → SDR BT.709 тонмаппингом **Hable** (сравнивались hable / mobius / reinhard / clip:
  hable — глубокий синий фон, халат без пересвета, естественная кожа), 1080×1920, 30 fps.
- **Картина сердца** (`../assets/photos/heart_poster.png`, вырезана из присланного референса
  1:1, 326×446) висит на стене справа вверху — x 680–1005, y 102–547, как на референсе.
  Положение привязано покадровым трекингом по предметам на столе.
  Баланс белого и перепад освещения стены подогнаны, мягкая тень рамки, реальный шум
  камеры перенесён на картину. Человек в зону картины не заходит ни разу (проверено
  по всем кадрам), поэтому маска не нужна.
- Цветокоррекция не делалась — будет общей на монтаже вместе с боковым ракурсом
  (`../side_angle_2/`, тот исходник SDR, этот — HDR → нужно сводить по цвету).

## Результат

- `output/front_2_poster_1080x1920.mp4` — H.264 ~5,6 Мбит/с (≈91 МБ), 30 fps, оригинальный звук — для просмотра и в git.
- `output/front_2_poster_master_1080x1920.mp4` — мастер CRF 14 (≈296 МБ) для монтажа; в git не кладётся, пересобирается скриптом.

Пересборка: `python3 scripts/poster.py` (просмотр кадров: `python3 scripts/poster.py 0.5 40 100`).
