# Обложки Reels «Для чего создан мой блог»

**Готовые обложки:** `output/cover_01.jpg` … `output/cover_15.jpg` — 1080×1920 (9:16), JPG 95 %.
Обзоры: `output/_обзор_9x16.jpg` (обложка целиком) и `output/_обзор_сетка_профиля_3x4.jpg`
(как она выглядит в сетке профиля).

- **Кадр** взят прямо из 4K-исходника (момент 1:39,8 — поднятый палец, жест «вопрос»), обработка
  та же, что в ролике (HDR→SDR, картина сердца на стене). Ника/водяного знака на обложках нет.
- **Сетка профиля** показывает только центр обложки 3:4 (y 240–1680). Весь текст стоит внутри
  этой зоны (верхняя строка — не выше y 262), поэтому виден и в ленте Reels, и в сетке;
  лицо и картину текст не перекрывает.
- **Текст за спиной** (№ 2, 5, 14): фигура врача вырезана нейросетью (RVM) и лежит поверх текста.

Загрузка: при публикации Reels → «Изменить обложку» → «Добавить из галереи / фотоплёнки».

## Пересборка

```bash
python3 scripts/base_frame.py                  # кадр из 4K-исходника → base/frame_*.png (нужен ../../sources)
python3 scripts/matte.py                       # маска фигуры (RVM) → base/person_z*.png
NODE_PATH=$(npm root -g) node scripts/render_covers.js [номера]   # cover.html → output/cover_NN.png
python3 scripts/export.py                      # JPG + обзоры
```
Тексты и раскладка всех вариантов — в `cover.html` (объект `V`). Шрифты — Fontsource 5.3.0
(лицензия OFL, оставлены только используемые файлы) и системный Inter.
