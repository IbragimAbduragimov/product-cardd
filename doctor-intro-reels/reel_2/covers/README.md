# Обложки Reels «Для чего создан мой блог»

**Готовые обложки:** `output/cover_01.jpg` … `output/cover_23.jpg` — 1080×1920 (9:16), JPG 95 %.
№ 16–23 — вторая серия: «Всего 10%?!» в одну строку; вариант 2 серии — в двух видах: № 17
(«ВСЕГО 10%?» по разметке заказчика) и № 21 (прежний вид, без «!»); № 22 и 23 — они же на кадре
со второго скриншота заказчика. В № 17, 21, 22, 23 «?» крупнее строки (1,45), «%» чуть меньше цифр (0,88). Обзоры каждой серии: `output/_обзор_1-15_…`,
`output/_обзор_16-23_…` — обложка целиком (9:16) и как она выглядит в сетке профиля (3:4).

- **Кадр** взят прямо из 4K-исходника, обработка та же, что в ролике (HDR→SDR, картина сердца
  на стене). Ника/водяного знака на обложках нет.
  - № 22, 23 — кадр прямо со второго скриншота заказчика (`reference/screenshot_cover_frame3.jpg`,
    руки сложены): ник со стены убран, 1,15× — через нейросетевое увеличение EDSR ×2
    (`base_from_screenshot.py`), основа — `base3/`.
  - № 16–21 — кадр со скриншота заказчика (`reference/screenshot_cover_frame.jpg`): 99,70 с
    исходника, поднятый палец, **рот закрыт**. Найден сравнением контуров лица и руки со
    скриншотом (`base_frame.py --ref`), основа — `base2/`.
  - № 1–15 — кадр 99,80 с (на 6 кадров позже, рот уже приоткрыт), основа — `base/`.
- **Сетка профиля** показывает только центр обложки 3:4 (y 240–1680). Весь текст стоит внутри
  этой зоны (верхняя строка — не выше y 262), поэтому виден и в ленте Reels, и в сетке;
  лицо и картину текст не перекрывает.
- **Текст за спиной** (№ 2, 5, 14, 16, 18): фигура врача вырезана нейросетью (RVM) и лежит поверх
  текста. В № 16 и 18 макушка задевает только низ букв — «1» в «10%» видна целиком.

## Пересборка

```bash
python3 scripts/base_frame.py                  # кадр из 4K-исходника → base/frame_*.png (нужен ../../sources)
python3 scripts/base_frame.py --ref reference/screenshot_cover_frame.jpg --out base2 --from 99.55 --to 99.90
python3 scripts/matte.py [--out base2]         # маска фигуры (RVM) → person_z*.png
python3 scripts/base_from_screenshot.py reference/screenshot_cover_frame3.jpg --out base3   # основа из скриншота
python3 scripts/darken.py --base base2 --z 1.15   # затемнение фона (стена, картина) по маске фигуры
NODE_PATH=$(npm root -g) node scripts/render_covers.js [номера]   # cover.html → output/cover_NN.png
python3 scripts/export.py                      # JPG + обзоры
NODE_PATH=$(npm root -g) node scripts/measure_text.js <папка> [номера] && python3 scripts/qc_text.py <папка>  # проверка
```
`qc_text.py` для каждого варианта печатает границы текста, зазор до картины и до фигуры
(или долю текста, скрытую фигурой) и предупреждает, если текст выходит из зоны сетки профиля.
Тексты и раскладка всех вариантов — в `cover.html` (объект `V`; `data-w` — ширина строки, под
которую подбирается кегль). Шрифты — Fontsource 5.3.0
(лицензия OFL, оставлены только используемые файлы) и системный Inter.
