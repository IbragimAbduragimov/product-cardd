## Монтажные решения

- **Структура:** зачем блог → наблюдение из практики → «лучшее лечение — профилактика» →
  факторы здоровья, медицина ≈10 % → цель блога → призыв подписаться.
- **Паузы** 0,6–1,4 с сокращены до естественных 0,4–0,6 с; запинок в речи практически нет.
  Каждая подрезка совпадает со сменой плана — «скачков» внутри кадра нет. 124 с → 112 с.
- **Убран повтор** «Согласно Всемирной организации здравоохранения» (79,7–83,0 с исходника):
  ссылка на ВОЗ уже прозвучала двумя фразами раньше. Возвращается одной строкой в `scripts/edl.py`.
- **Единый звук.** Во всём ролике звучит только фронтальный дубль (петличный микрофон) — голос не
  меняется при смене ракурса. Боковое видео — отдельный дубль, поэтому его кадры подогнаны под
  этот звук по времени: DTW-выравнивание речи двух дублей (MFCC), `scripts/retime.py`.
  Проверка: звук бокового дубля через ту же карту совпадает с фронтальным со сдвигом 5–10 мс
  (r = 0,87–0,90); пословная разметка — медиана 13–23 мс; привязка кадров к исходнику — 1 мс.
- **Боковой ракурс — 2 раза:** «Я не раз наблюдал… пациенты воспринимают» (до паузы, которой нет
  в боковом дубле) и «Осознав это, я понял…». Цвет бокового ракурса подогнан по стене.
- **Приближения** (всегда уменьшение из 4K, без потери качества, максимум 1,7×): 1,22–1,26
  (начало), 1,36, 1,58→1,70 (плавный наезд на «О полном излечении…»), 1,70 («Лучшее лечение…»),
  1,26–1,30, 1,62, 1,30→1,38, 1,66; возвраты к общему плану на «Как вы уже знаете»,
  «Давайте обратимся к цифрам» и в финале. На приближениях картина на стене слегка смягчается
  (эффект глубины резкости).
- **Фото не используются** (по просьбе заказчика): на их местах — фронтальные планы 1,32×
  («Встречаясь с различными историями заболеваний…», «делиться профессиональными знаниями…»).
- **Водяной знак** «abduragimov_cvs» — левый верхний угол, весь ролик: антиква с широкой
  разрядкой, как на присланном референсе (Liberation Serif 36 px), без подложки, выше заголовков.
- **Графика** (HTML/SVG → Chromium, по кадрам, синхронно со словами):
  1. «Здоровье определяется задолго до болезни» — шкала лет до болезни;
  2. «Остаётся лечить и сдерживать» — схема течения болезни без лечения / с лечением,
     меньше обострений, до уровня здоровья не возвращается (схема без чисел);
  3. «Четыре фактора» — образ жизни, наследственность, окружающая среда, здравоохранение;
  4. «10 %» → «90 %» — сетка 100 точек: вклад медицины и других факторов.
- **Заголовки** только на ключевых мыслях (без ФИО в начале): @abduragimov_cvs,
  «Лучшее лечение — это профилактика», «Знания + готовность им следовать», «Цель блога».
- **Подписи внизу** (вместо полных субтитров): «Для чего создан мой блог», «О полном излечении
  речи уже не идёт», «Пересылайте тем, кому желаете здоровое будущее».
- **Звук:** голос (шумоподавление по профилю пауз, мягкая компрессия, −14 LUFS) и 10 тихих
  синтезированных акцентов: 2 «воздушных» перехода на графику, 4 щелчка на факторах,
  3 низких удара («болезнь», «профилактика», «10 %»), мягкое нарастание на финальной плашке.
- **Цвет:** без стилизации и LUT. HDR фронта переведён в SDR (Hable), светлые тона возвращены
  к яркости обычной съёмки iPhone (как у бокового SDR-дубля); боковой ракурс подогнан по
  цвету стены. Ретушь лица не применялась — она снижала бы чёткость.

## Проверка фактов

Распределение «образ жизни 50 % / наследственность 20 % / среда 20 % / медицина 10 %»
часто приписывают ВОЗ, но первоисточника ВОЗ нет; эти оценки восходят к работам
Ю. П. Лисицына и Ю. М. Комарова. Поэтому на экране — четыре фактора **без** непроверенных
процентов. Оценка «медицина ≈10 %» подтверждается независимо: McGinnis et al., *Health Affairs*,
2002; Kaplan & Milstein, *Annals of Family Medicine* 17(3), 2019 (≈10 % преждевременной
смертности связано с недоступностью/недостатками медицинской помощи). Речь врача не менялась.

## Видеоматериалы

Из этой среды недоступны стоковые сайты (Pexels, Pixabay, Mixkit, Wikimedia и др.).
Поэтому вставки — собственная графика и второй ракурс. Если загрузить стоковые клипы
(например, с Pexels/Mixkit) в релиз репозитория, их можно подставить в `scripts/edl.py`.

## Пересборка

```bash
pip install sherpa-onnx opencv-contrib-python-headless onnxruntime scipy pillow numpy
python3 scripts/edl.py && python3 scripts/cues.py          # монтажный лист, субтитры, привязки
NODE_PATH=$(npm root -g) node scripts/render_scenes.js      # графика (Playwright + Chromium)
python3 scripts/side_shots.py                               # боковые планы (RVM, нужна модель)
python3 scripts/audio.py                                    # звук
python3 scripts/assemble.py                                 # итоговый ролик
python3 scripts/assemble.py --stills 10 50 98               # отдельные кадры для проверки
```
Распознавание речи (`build/asr.json`, `build/vad.json`) — GigaAM v2 + Whisper turbo + Silero VAD
(sherpa-onnx), см. `scripts/words.py`, `scripts/vad.py`.
