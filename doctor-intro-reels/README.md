# Видео-знакомство с врачом-ординатором — Instagram Reels

> Новая съёмка: подготовленный боковой ракурс лежит в [`side_angle_2/`](side_angle_2/README.md)
> (стабилизация, приближение из 4K, замена стены синим фоном), фронтальная камера — в
> [`front_2/`](front_2/README.md) (HDR→SDR, картина сердца на стене). Монтаж нового ролика — впереди.

**Готовый файл:** `output/doctor_intro_reels_1080x1920.mp4`
1080×1920 (9:16), 30 fps, H.264 High, AAC 256 kbps / 48 kHz, −14 LUFS, 2:16.
Субтитры вшиты в изображение; отдельно лежат в `output/subtitles_ru.srt`.

## Что сделано

- **Оригинал целиком.** Основа — фронтальная камера, вся речь по порядку, без вырезанных пауз и запинок.
  Два фронтальных файла — части одной записи, они перекрываются на ~4,7 с (звук на перекрытии
  совпадает побитово). Склейка сделана в паузе на T=76,5 с, поэтому речь непрерывна: ничего
  не потеряно и ничего не повторяется.
- **Боковой ракурс — 2 раза** (синхронизирован по звуку с точностью до кадра):
  37,4–41,4 с («Такое решение положило начало…») и 75,0–80,2 с (закрывает стык файлов).
- **Вставки:** фото у флагов на «Ещё со школы…», фото доклада на «научных кружках»,
  видео с мероприятия на «участвовал на международных конференциях и занимал призовые места»,
  фото из операционной на «Сейчас я являюсь старостой ординаторов…».
- **Титры** в верхней безопасной зоне Reels: имя и специализация, место рождения, 100 и 290 баллов,
  университет, диплом с отличием, ординатура (40+ претендентов), староста ординаторов; финальная плашка.
- **Субтитры:** распознавание GigaAM v2 (пословные таймкоды) со сверкой по Whisper turbo,
  пунктуация вручную, умеренные акценты цветом.
- **Звук:** только оригинальная речь — фильтр низких частот, мягкое шумоподавление, лёгкая эквализация
  и компрессия, нормализация. Задержка фильтров скомпенсирована (синхрон 0 мс по всей длине).
  Музыка синтезирована с нуля (своя, без лицензий) и звучит примерно на 17 дБ ниже голоса с мягким дакингом.
- **Цвет:** сдержанная коррекция (контраст, нейтральная кожа, лёгкий холодный оттенок в тенях), лёгкая виньетка.

## Пересборка

```bash
pip install sherpa-onnx scipy pillow numpy   # ffmpeg с libx264 должен быть установлен
export SRC_DIR=/путь/к/исходным/видео         # 4 исходных файла с камер
python3 scripts/music.py                       # build/music.wav
python3 scripts/graphics.py                    # build/overlay.mov (титры + субтитры)
python3 scripts/render.py                      # звук → видео → .srt
```

Все времена, вставки, титры и тексты субтитров задаются в `scripts/timeline.py`.
Распознанная речь с таймкодами: `build/asr.json`, `build/master_words.json`.
