## Что сделано

**Боковое (`out/side_instagram.mp4`)**
- стабилизация: кадр зафиксирован относительно кадра 1500 (`work/T.npy` — посчитано `work/track.py`);
- белая стена с панелями и полоска скотча слева заменены синим фоном (зона `x<174`, выше края стола `y < 720 + 0.18x` в координатах стабилизированного кадра 720×1280; человек защищён маской MediaPipe);
- полоска со скотчем у руки убрана: внутри её столбца защищаются только кожа и гладкий белый рукав, тёплый серый скотч заменяется фоном;
- обрезан низ (пол, ножки стола): окно `x=20..690`, низ на `y=1060`, сверху достроено синим; стабилизация + кроп + масштаб делаются ОДНИМ Lanczos-преобразованием (без потерь на повторных пересчётах).

**Фронтальное (`out/front_instagram.mp4`)**
- постер `work/poster.png` наложен в точке `(659, 83)` кадра 1080×1920 — как на образце; ник не добавлен.

**Оба**
- очистка фона от «мыла» (пятен сжатия) — `work/cleanbg.py`: синий фон заменяется гладкой, стабильной во времени версией самого себя, человек/стол/предметы не затрагиваются;
- лёгкая резкость + мелкое зерно, x264 CRF 16 (`-tune film`, `aq-mode=3`, maxrate 6M — файлы < 100 МБ).

**Звук (оба)** — `work/decreak.py`: убран скрип табуретки в конце (два треска; боковое 111.035–111.125 и 111.21–111.30 с, фронтальное 115.25–115.35 и 115.43–115.54 с). Спектральное восстановление: в окне треска каждая частота ограничивается уровнем звука до/после, голос не режется.

## Как перегенерировать

```bash
apt-get install -y libegl1 libgles2      # нужно для mediapipe
pip install opencv-contrib-python-headless mediapipe
cd video-edit && ./fetch_sources.sh
python3 work/render_side.py 0 3351 out/side_instagram.mp4
python3 work/render_front.py 0 3556 out/front_instagram.mp4
# звук без скрипа и замена дорожки
ffmpeg -i videos/VID_20261105_144306_140.mp4.mov -vn -ac 1 -ar 48000 side.wav
python3 work/decreak.py side.wav side_fixed.wav 111.035:111.125 111.21:111.30
ffmpeg -i out/side_instagram.mp4 -i side_fixed.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest side_final.mp4
# фронтальное аналогично: 115.25:115.35 115.43:115.54
```
Аргументы: начальный кадр, количество кадров, выходной файл (удобно для коротких превью).

## Монтаж v3 (`out/montage_v3_clean.mp4`, 1:55) — без инфографики

Скрипт `work/edit.py`, таймлайн `SHOTS` в секундах фронтальной камеры. Основа — фронтальное видео,
звук целиком с фронтального микрофона (`front_fixed.wav`, обрезан 1.40–116.40, loudnorm ≈ −15 LUFS).
Синхронизация камер: `side_t = front_t − 4.2066` (по взаимной корреляции звука).

Только ПЛАВНЫЕ наезды/отдаления (пользователь просил без резких «щелчков»): внутри кадра масштаб
непрерывный, со сглаживанием (нулевая скорость в каждой ключевой точке), ≤ 1.7 %/с. Скачок масштаба — только на смене камеры.

## Инфографика — варианты на «10% / 90%» (`out/info/`)

Исходники в `infographics/` (HTML/SVG + `common.js`, шрифт Montserrat). Анимация задаётся функцией `render(t)`
от времени фронтальной камеры и привязана к словам (см. `transcript.md`). Кадры: `node infographics/shoot.js A 4.5 14.0 30 seq_A`
(прозрачный PNG 1080×960, верх кадра), затем overlay на монтаж (`-ss 3.1 -t 9.5`).
A — кольцевая диаграмма, B — шкалы на панели, C — 100 клеток, D — только текст. Пользователь выбирает вариант.

Пользователь выбрал **вариант A (кольцо)**. Для удержания внимания — два «тизерных» варианта на его основе (`infographics/Q.js`, `Q1.html`, `Q2.html`):
- **Q1 «Знаки вопроса»** — 90% разбиты на три тёмных сектора с пульсирующим «?», в центре «90% · от чего?»;
- **Q2 «Засекречено»** — сектора цветные, проценты видны, названия закрыты мерцающими плашками, в центре «3 фактора».
Факторы раскрываются в начале своих глав: `REVEAL={life:14.35}` (дальше env 42.2, her 69.8); окно повторного показа `W2`.
