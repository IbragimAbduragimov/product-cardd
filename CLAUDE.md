# product-cardd

Здесь хранится монтаж видео для Instagram. Всё описано в `video-edit/README.md`:
исходники лежат в GitHub Release `Videos` (скачиваются `video-edit/fetch_sources.sh`),
готовые ролики — в `video-edit/out/`, скрипты монтажа — в `video-edit/work/`.
Рабочие файлы/кадры для проверки складывать вне репозитория (scratchpad), в git — только итог.
